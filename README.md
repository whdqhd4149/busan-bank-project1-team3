# 🏦 부산은행 금융 웹 서비스 - Admin & Customer Web

Spring Boot 기반의 부산은행 금융 웹 서비스 팀 프로젝트입니다.  
고객 화면과 관리자 화면을 중심으로 구성된 웹 서비스입니다.

---

## 📌 프로젝트 소개

본 프로젝트는 부산은행 금융 서비스를 웹 환경에서 제공하기 위한 팀 프로젝트입니다.  
Spring Boot, MyBatis, Oracle을 기반으로 고객 기능과 관리자 기능을 구현했습니다.

---

## ✨ 주요 기능

### 👤 고객 기능

- 로그인 / 회원가입
- 펀드 상품 목록 및 상세 조회
- 펀드 수익률 및 NAV 조회
- 투자 성향 분석
- 고객센터 / 챗봇

### 🛠 관리자 기능

- 펀드 상품 목록 및 상세 조회
- 펀드 상품 등록 / 수정 / 승인 / 반영 예약
- 정보공시 / 수시공시 / 펀드시황 / 가이드 / 펀드정보 게시물 관리
- 회원 관리
- 고객센터 관리
- 펀드 카테고리 관리
- 검색어 관리

---

## 🧑‍💻 담당 역할

### 관리자 펀드 상품 관리
- 펀드 상품 목록 조회 기능 구현
- 돋보기 버튼 클릭 시 선택한 펀드 상품 상세 조회 기능 구현

### 금융 게시물 관리
- 정보공시, 수시공시, 펀드시황, 가이드, 펀드정보 게시물 CRUD 구현
- 게시물 목록 검색 및 페이지네이션 처리
