# 🏦 부산은행 금융 웹 서비스 - Admin & Customer Web

Spring Boot 기반의 부산은행 금융 웹 서비스 팀 프로젝트입니다.  
고객 화면과 관리자 화면을 중심으로 구성된 웹 서비스이며, 금융 상품 조회, 투자 성향 분석, 공시 게시판, 관리자 상품 관리 기능을 제공합니다.

---

## 📌 프로젝트 소개

본 프로젝트는 부산은행 금융 서비스를 웹 환경에서 제공하기 위한 팀 프로젝트입니다.

고객은 펀드 상품을 조회하고 투자 성향 분석을 진행할 수 있으며,  
관리자는 펀드 상품과 금융 게시물, 고객센터 데이터를 관리할 수 있도록 구성했습니다.

Spring Boot, MyBatis, Oracle을 기반으로 고객 기능과 관리자 기능을 분리하여 구현했습니다.

---

## 👥 팀 구성

- 팀장: 정순권
- 팀원: 이종봉, 최상규, 박민규, 설유진

---

## ✨ 주요 기능

### 👤 고객 기능

- 로그인 / 회원가입
- 펀드 상품 목록 및 상세 조회
- 펀드 수익률 및 NAV 조회
- 투자 성향 분석
- 고객센터 / 챗봇

### 🛠 관리자 기능

- 펀드 상품 목록 및 상세 조회
- 펀드 상품 등록 / 수정 / 승인 / 반영 예약
- 정보공시 / 수시공시 / 펀드시황 / 가이드 / 펀드정보 게시물 관리
- 회원 관리
- 고객센터 관리
- 펀드 카테고리 관리
- 검색어 관리

---

## 🧑‍💻 담당 기능

### 관리자 펀드 상품 관리

관리자 페이지에서 등록된 펀드 상품 목록을 조회하고, 목록의 돋보기 버튼을 클릭하면 선택한 펀드 상품의 상세 정보를 모달 화면으로 확인할 수 있도록 구현했습니다.

- 펀드 상품코드 기준 상세 데이터 조회
- 상세 모달 화면에 펀드명, 상품코드, 수익률, 차트, PDF 문서 링크 표시
- 기존 화면 구조를 분석하여 상세 데이터 조회 흐름 연결

### 금융 게시물 관리
